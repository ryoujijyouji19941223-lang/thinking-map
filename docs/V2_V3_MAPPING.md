# v2 → v3 対応表

## 結論

v3 の11理論領域で v2 を置き換えない。

- **v2 A〜F** = 測定結果の地図
- **v3 11領域** = 課題設計と解釈のための Process Lens

この二軸化によって、「専門家の理論をそのまま能力点にする」誤りを避ける。

## v2測定軸への追加

### A 入力経路
維持:
- 文字
- 音声
- 図・画像

v3追加候補:
- 音声+文字
- 図+文字
- 時系列提示
- 制限時間あり/なし

### B 表象
維持:
- 逐語
- 意味
- 物体イメージ
- 空間イメージ
- 抽象関係
- 状況モデル

v3追加:
- **身体的外在化**: gesture / action
- **外部表象**: diagram / map / note

これらは「能力」ではなく Strategy / condition としてまず記録する。

### C 情報操作
維持:
- 因果
- 時系列
- 統合
- 予測
- 比較
- 矛盾
- 仮説比較
- 視点変換

v3追加:
- 介入推論
- 反実仮想
- 確率更新
- 結果を知った後の再評価
- 時間圧下のシミュレーション

### D 構造化
維持:
- 細部
- 全体
- 分類
- ルール発見
- 階層化
- 例外検出

v3追加:
- 関係構造マッピング
- 表面類似 / 構造類似の識別

### E 社会的認知
すべて維持:
- 人物意図
- 感情推測
- 他者視点
- 知識状態追跡

v3追加:
- 自分に好都合/不都合な人物情報による解釈差
- 視点座標の明示的切替

### F メタ認知
v2の Calibration Bias / Accuracy / Resolution を維持。

v3追加:
- 説明前→説明後の理解度修正
- 学習直後→遅延後の予測誤差
- 新情報前→後の自信変化
- 結果提示前→後の判断品質評価差

## v3で新設する課題群

既存15課題とは別に、以下を新設候補とする。

1. 選択的注意 / 注意切替
2. 事実・推測・欠落の分離
3. 外在化効果（図・ジェスチャー）
4. 構造類推と転移
5. 説明深度の錯覚
6. 検索練習と遅延保持
7. 介入・反実仮想
8. 動機づけられた証拠評価
9. 確率校正・更新
10. 結果バイアス
11. 異常察知・時間圧判断

## 実装優先度

### Wave 1
既存v2を壊さず追加しやすいもの:
- 事実 / 推測 / 欠落
- 説明前後の理解度
- 仮説への確率付与
- 新情報後の更新
- 結果バイアス
- 構造類推

### Wave 2
UI・保存構造の変更が必要:
- 図を描く条件
- ジェスチャー条件
- 遅延テスト
- 複数日にまたがる校正

### Wave 3
十分な問題生成・データ蓄積が必要:
- 熟練 / 暗黙知
- 長期予測校正
- 個人内の安定性
