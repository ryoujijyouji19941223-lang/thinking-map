# Wave 1 デバッグチェックリスト

Wave 1 の6モジュールを実際にプレイして、修正点を集めるための記録用。

## 共通UI

- [ ] スマホで文字が小さすぎない
- [ ] ボタンが押しにくくない
- [ ] 長文で画面が不必要に縦長にならない
- [ ] 戻る場所が分かる
- [ ] 進行状況が分かる
- [ ] 入力途中で誤操作しにくい
- [ ] 自信度スライダーの意味が分かる
- [ ] 結果画面が数字だらけになっていない
- [ ] 結果文が能力を断定していない
- [ ] リセットが意図せず押されにくい

## 問題設計

- [ ] 問題文だけで測定意図が露骨に分からない
- [ ] 選択肢を見るだけで正解が分からない
- [ ] 誤答が「馬鹿げた選択肢」になっていない
- [ ] 同じ正解パターンが続いていない
- [ ] 文章の長さではなく狙った認知処理が難易度を作っている
- [ ] 問題間で構造が重複しすぎていない
- [ ] 専門知識の有無が主な得点源になっていない
- [ ] 曖昧で複数正解になる問題がない

## 01 Fact / Inference / Missing

確認:
- [ ] 「事実」「推測」「不足」の区別が分かりやすい
- [ ] 事実欄へ自然に推測を書きたくなる程度の課題になっている
- [ ] 不足情報が無限に挙げられる問題になっていない
- [ ] 参照ポイント表示が「唯一の正解」に見えない

既知の技術課題:
- 自由文採点は現在文字列一致のため、言い換えに弱い。

## 02 Explain Then Re-rate

確認:
- [ ] 対象を知っている人だけが有利すぎない
- [ ] 「部品名クイズ」になっていない
- [ ] 説明前の自己評価が説明後回答を強くアンカーしすぎない
- [ ] 不明点を見つけたことが失点のように見えない
- [ ] 3題の難易度差が大きすぎない

既知の技術課題:
- 説明そのものの意味・因果連鎖はまだ自動採点していない。

## 03 Structural Analogy

確認:
- [ ] 表面が似た誤答が露骨すぎない
- [ ] 正解だけ文体が整っていないか
- [ ] 「連鎖」「循環」など問題文中の言葉だけで解けないか
- [ ] 対応説明が本当に構造理解を補足しているか
- [ ] 題材知識ではなく関係構造で解けるか

既知の技術課題:
- 対応関係の自由記述は未採点。

## 04 Observation / Intervention / Counterfactual

確認:
- [ ] 「観察は断定できない」が毎回正解という攻略法になっていない
- [ ] 介入と反実仮想の違いが説明なしでも測れるか
- [ ] 正解文だけ慎重な言い回しになっていない
- [ ] 因果モデルが明示された問題とされない問題を混同しない
- [ ] 一般知識より提示されたモデルを使って解けるか

## 05 Probability Update

確認:
- [ ] 合計100%入力が面倒すぎない
- [ ] スマホで数字入力しやすい
- [ ] 新証拠が強すぎて更新方向が自明すぎない
- [ ] 「全部0か100」に誘導されない
- [ ] 最終確率の絶対値を正解扱いしていない
- [ ] 更新しないことが妥当な問題も将来必要か検討

既知の技術課題:
- 現状は主に「更新方向」を見ており、長期的な calibration はまだ測っていない。

## 06 Outcome Blind Decision

確認:
- [ ] 結果を見る前の情報だけで判断できる
- [ ] 結果の良し悪しが派手すぎて評価変更を強制していない
- [ ] 3問続けると「結果に騙されないテスト」と悟られすぎない
- [ ] 良い結果 / 悪い結果の順序効果が強くない
- [ ] 判断目的が曖昧でない
- [ ] 評価変更を自動的にバイアス扱いしていない

## 保存・データ

- [ ] 6モジュールの localStorage キーが衝突しない
- [ ] 再実施時の上書き方針を決める
- [ ] 過去セッション履歴を保存するか検討
- [ ] 日時・問題ID・phase・process_lens が残る
- [ ] 将来の delayed / transfer と紐付けられるID設計にする

## ユーザー報告テンプレート

バグや違和感は以下だけあれば追跡できる。

- モジュール:
- 問題番号:
- 何を押した / 何を書いた:
- 起きたこと:
- 本来どうなってほしかった:
- 問題文そのものへの違和感:
- スクリーンショット（あれば）:

## Wave 1 の終了条件

- 6モジュールをPCとスマホで最低1周
- 操作不能バグがない
- 各問題の曖昧さをレビュー
- 選択肢だけで解ける問題を修正
- 結果文の過剰断定を修正
- 自由文採点を「未採点の観察データ」と明示するか、意味採点を導入
- 修正後に再度1周
