# Learning / Desirable Difficulties — Robert & Elizabeth Bjork

## 中心概念
練習中の高い performance は、そのまま長期 learning を意味しない。

主な要素:
- spacing
- interleaving
- retrieval practice
- varying conditions
- storage strength / retrieval strength

## 思考の地図への変換
同じ内容を異なる学習条件へ割り当て:
- 再読
- 思い出す
- まとめて練習
- 間隔を空ける
- 同種連続
- 混合

即時成績だけでなく遅延成績と転移を見る。

## メタ認知
学習直後に「明日どれくらい覚えていると思うか」を予測させ、実績と比較する。
