# Expertise / Naturalistic Decision Making — Gary Klein

## 中心概念
現実の熟練判断は、いつも全選択肢を列挙して比較する形ではない。

経験によって:
- パターンを認識する
- 微妙な違いを識別する
- 典型からの異常を察知する
- メンタルモデルで先を予測する
- 最初に浮かんだ行動案を頭の中で試す
といった暗黙知が働く。

## 思考の地図への変換
- 制限時間付き場面
- 一部情報だけ提示
- 時系列で状況変化
- 「何が気になった？」を記録
- 判断後に認知的デブリーフ

比較:
- 初心者
- 同領域の経験者
- 同じ人の反復学習

## 重要
単なる「直感が速い」を熟練としない。経験領域に依存する。
