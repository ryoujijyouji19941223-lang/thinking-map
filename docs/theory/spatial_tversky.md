# Spatial / Embodied Thinking — Barbara Tversky

## 中心概念
- spatial thinking は visual imagery と同一ではない
- 人は言葉を空間的モデルへ変換する
- gesture は理解・記憶・説明を助けることがある
- diagram や map は「思考を外へ出す」道具になる
- 空間的な関係表現は、時間・社会関係・抽象概念にも使われる

## 思考の地図への変換
同じ課題を:
- 頭だけで解く
- 図を描く
- ジェスチャー自由
- 手を動かさない
で比較する。

別軸として:
- 視覚イメージ
- 空間関係操作
- 外在化による改善量
を記録する。

## 重要
「映像が浮かばない = 空間思考が弱い」としない。
