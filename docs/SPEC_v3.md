# 思考の地図 v3 仕様書（初期版）

## 1. 目的

「得意な認知タイプ」を一度で決めるのではなく、人が情報を受け取ってから判断するまでの処理を複数段階に分け、条件差・再現性・学習効果まで観察する。

中心となる問いは次の通り。

- 何に注意が向いたか
- 何を事実として観察したか
- どの形式で頭の中に表現したか
- 共通する関係構造を抽出できたか
- 本当に理解しているか、自分で把握できているか
- 時間が経っても保持・転移できるか
- 相関と因果を区別できるか
- 自分の信念で証拠の評価が変わるか
- 不確実性をどの程度の確率として扱うか
- 結果と意思決定の質を分けられるか
- 時間圧のある現実的状況で何を手掛かりに判断するか

## 3. v3 の基本構造

### Phase A: 初見測定
技法を教える前に課題を行う。元々の傾向を記録する。

### Phase B: 専門家レッスン
対象となる考え方を短く学ぶ。例: 観察と推測を分ける、比較によって関係構造を取り出す。

### Phase C: 練習
学んだ技法を意識的に使う。

### Phase D: 転移テスト
見た目や題材を変えた課題で、技法が別場面にも使えるかを見る。

### Phase E: 遅延テスト
可能な領域では翌日以降にも再テストし、短期成績と保持を分離する。

## 4. 11 Process Lens

### 4.1 注意
基礎: Amishi Jha

測る候補:
- 選択的注意
- 広い状況把握
- 注意の切替
- 目標の保持
- 注意逸脱への気づき

### 4.2 観察
基礎: Amy Herman

測る候補:
- 事実と解釈の分離
- 欠落情報の検知
- 情報の重要度
- 観察の言語化
- 他者の観察との比較

### 4.3 空間・身体・外在化
基礎: Barbara Tversky

視覚イメージと空間表象を分ける。

測る候補:
- 空間関係保持
- 視点変換
- 図式化
- ジェスチャー利用効果
- 図・配置による外部記憶
- 社会関係の空間的マッピング

### 4.4 類推・関係構造
基礎: Dedre Gentner

測る候補:
- 表面的類似と構造的類似の区別
- 共通関係の抽出
- 比較による抽象化
- 別題材への解法転移

### 4.5 理解の自己評価
基礎: Frank Keil / Leonid Rozenblit

測る候補:
- 説明前の理解度自己評価
- 段階的説明の完成度
- 説明後の自己評価修正
- 「対象が見える時」と「記憶だけ」の差

### 4.6 学習・保持・検索
基礎: Robert & Elizabeth Bjork

測る候補:
- その場の流暢さと長期保持の差
- 再読と検索練習の差
- 間隔効果
- 交互学習とブロック学習
- 自分の学習状態の予測精度

### 4.7 因果推論
基礎: Judea Pearl

初期版では数式能力を測るのではなく、概念的な区別を中心にする。

測る候補:
- 相関と因果
- 交絡
- 介入
- 反実仮想
- 因果方向
- 欠落した前提への気づき

### 4.8 信念・動機づけられた推論
基礎: Julia Galef

測る候補:
- 自分に好都合/不都合な証拠の評価差
- 反証への抵抗
- 代替仮説の生成
- 信念修正
- 自信と柔軟性の関係

### 4.9 予測・確率校正
基礎: Philip Tetlock

測る候補:
- 曖昧語を確率へ変換
- 50/60/70/90%の使い分け
- 新情報による更新幅
- 予測精度と自信の対応
- 長期的な校正

### 4.10 不確実な意思決定
基礎: Annie Duke

測る候補:
- 決定前の可能な結果の列挙
- 結果と判断品質の分離
- hindsight/resulting の影響
- 複数選択肢の確率比較
- 将来の自分への事前対策

### 4.11 熟練・暗黙知・時間圧
基礎: Gary Klein

測る候補:
- 典型パターン認識
- 異常察知
- 状況の素早いサイズアップ
- 頭の中での行動シミュレーション
- 何を手掛かりにしたかの言語化
- 事後デブリーフでの気づき

- 「知能が高い/低い」

## 9. 科学的な位置づけ

各専門家の理論・実験は課題設計の根拠候補として使用するが、本アプリ自体が妥当性検証済みの心理検査であることを意味しない。

今後必要:
- 同一構成概念を複数課題で測定
- 再テスト信頼性
- 課題間相関
- 年齢・言語・端末条件などの影響確認
- 出題順効果の確認
- 学習効果と特性差の分離
