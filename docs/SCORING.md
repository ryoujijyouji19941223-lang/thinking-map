# スコアリング設計（暫定）

## 1. 単一総合点を主役にしない

v3では「総合認知力 87」のような単一値を中心にしない。

優先する表示:
- 条件差
- 自信との対応
- 情報更新
- 保持
- 転移
- 再現性

## 2. 基本指標

### Accuracy
課題ごとの正答・部分正答。

### Confidence
回答時の自信度 0–100。

### Calibration
同程度の自信を付けた回答群で、実際の正答率と比較する。

例:
- 自信80%の回答が長期的に約80%正しい → よく校正されている
- 自信90%だが正答率50% → 過信傾向
- 自信40%だが正答率90% → 過小評価傾向

少数問では断定しない。

### Update
追加情報後に回答・確率・自信がどう変わったか。

### Retention
一定時間後にどれだけ保持されたか。

### Transfer
見た目の違う課題へ同じ原理を利用できたか。

### Externalization Gain
図・メモ・ジェスチャー等を使える条件での変化。

## 3. 時間

速さ単独を能力とみなさない。

同じ正確さなら時間差は参考にするが、
- 慎重さ
- 読解速度
- 入力方式
- 端末
の影響を分離する必要がある。

## 4. レポート例

「観察 82点」ではなく:

- 画像課題では事実と推測をよく分離した
- 文章課題では推測を事実として答える割合が増えた
- 欠落情報への気づきは画像より文章で高かった
- 自信度は平均78%、実際の正答率は74%だった
- 追加証拠が強い時には結論を更新したが、弱い証拠では維持する傾向が見られた

## 5. データが少ない時

「傾向あり」ではなく「暫定」とする。

最低限、同じ指標が複数問題・複数形式で再現してからプロファイルに強く反映する。
