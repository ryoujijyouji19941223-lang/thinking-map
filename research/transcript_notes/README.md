# Transcript Notes

ここには元文字起こしそのものではなく、研究・設計に必要な要点の要約を置く。

## 方針

- 長い文字起こしをそのまま転載しない
- 専門家の用語を可能な限り保持する
- 「本人の主張」「研究結果」「こちらの設計案」を分ける
- 一般向け解説動画は本人講義と区別する
- 同一内容の重複は統合する
- 課題案へ変換する際、元研究とアプリ独自部分を明記する

## ノートのテンプレート

```
# 専門家 / 理論

## Source
ファイル名 / 講演名

## Source says
文字起こしが実際に述べている内容の要約

## Measurement idea
思考の地図へ変換する案

## Risk
誤解・過剰解釈・診断化の危険

## Validation needed
追加で検証すべき点
```
